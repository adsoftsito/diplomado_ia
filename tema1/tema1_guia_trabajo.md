# Guía de trabajo · Tema 1 · Red de Hopfield

## Materiales base
- `tema1_hopfield.pptx`
- `tema1_hopfield.xlsx`

## Meta de aprendizaje
Construir una red de Hopfield con operaciones de álgebra lineal y validar recuperación de patrones.

## Actividades
1. Representa al menos 2 patrones bipolares (+1/-1).
2. Calcula la matriz de pesos W (con diagonal en cero).
3. Ejecuta actualización de estados para un patrón con ruido.
4. Programa la red en Java o C (sin agentes de IA).
5. Compara salida esperada vs salida obtenida.

## Checklist de verificación
- [ ] Dimensiones de vectores y matrices correctas.
- [ ] Diagonal de W igual a cero.
- [ ] Recuperación correcta de al menos un patrón con ruido.
- [ ] El código implementa la regla de actualización correctamente.

## Evidencias de entrega
- Tabla de cálculo matricial.
- Código fuente (Java o C).
- Resultados de pruebas.
