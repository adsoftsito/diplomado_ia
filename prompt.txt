En un contexto de profesor y participante de un Diplomado parar mejorar las experiencia de aprendizaje de mis estudiantes,  denominado: IAGen para la docencia universitaria: construcción de experiencias de aprendizaje en la Universidad Veracruzana.  El objetivo de este proyecto es ayudar a los Estudiantes en entender, analizar y crear redes neuronales profundas desde cero. Realizando los calculos a nivel de Algebra lineal, multiplicando matrices, realizando transpuestas, suma de matrices, calculo de diagonales, entre otras. El estudiante debe crear una Red Hopfield con solo calculos matematicos, posteriormente debera programarla en Java o C sin usar Agentes de IA. Como segundo tema el estudiante debera crear desde cero una Red neuronal multicapa, aplicar funciones de activacion, realizar una simulacion en Excel, y posteriormente en Python pero sin usar frameworks, se deberan calcular los pesos W y b para cada capa y comprobar sean correctos. Finalmente como tercer tema el estudiante aprendera a modelar redes neuronales profundas usando frameworks como Tensorflow, el estudiante codificara los ejemplos de Hopfield, y la red multicapa del tema pero ahora usando Tensorflow y comprobara que los pesos W y b proporcionar resultados parecidos a los programas hechos desde cero.
